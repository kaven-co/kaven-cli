## 4. Technical Gotchas (For Developers)

1. **Imports**: In this Pure ESM environment, ALL relative imports **must** include the `.js` extension (e.g., `import { x } from './file.js'`), even though the file on disk is `.ts`.
2. **Testing**: Use `pnpm run test` (which calls `node --import tsx --test`). Do not attempt to use Vitest or Jest.
3. **Mocks**: Use the native `mock.method(object, 'methodName')`. Note that native mocks do not support `mockResolvedValue` directly; use `mock.mockImplementation(async () => ...)` instead.
